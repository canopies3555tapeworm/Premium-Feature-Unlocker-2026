### Is OmniPatch safe to use? Does it contain tool?

OmniPatch is a local configuration tool that modifies application files on your system. Always download from official sources and run anticomponent scans as you would with any executable. We recommend using it in a test environment first.

### Which specific AI applications are currently supported?

OmniPatch supports ChatGPT, Claude, Microsoft Copilot, Cursor, GitHub Copilot, Devin, and JetBrains AI Assistant. We continuously work to add support for additional applications.

### How often is OmniPatch updated to maintain compatibility?

We aim to release updates within 2-3 weeks following major version releases of the supported AI applications. Check the repository's Releases tab for the latest version.

### Do I need an active subscription or account for the target AI service?

Yes, OmniPatch works by modifying local application states. You must have the base application installed and, in most cases, a registered account (which can be free-tier) for the patch to apply.

### Can I use OmniPatch on macOS or Linux?

No, OmniPatch is a Windows-only desktop utility (.exe). It is designed specifically for the Windows versions of the supported AI applications.

### What should I do if a patch fails or the application stops working?

First, ensure you are running the latest version of OmniPatch and the target app. You can often 'Unpatch' from within OmniPatch to revert changes. If issues persist, visit the repository's Issues section for community help.
